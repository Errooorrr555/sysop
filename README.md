# SysOpCore

Repository now contains a WPF prototype for SysOpCore (dark dashboard + card actions) under `SysOpCore/`.

## Build (Windows with .NET 8 SDK)

```bash
dotnet build SysOpCore/SysOpCore.csproj
```

## Publish portable executable

```bash
dotnet publish SysOpCore/SysOpCore.csproj -c Release
```
